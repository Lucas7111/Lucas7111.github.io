Hoe maakt een computer verschillende kleuren?

Op je telefoon zie je miljoenen kleuren. Maar hoe weet een computer welke kleur hij op het scherm moet laten zien?

Wat is een kleurmodel?

Een kleurmodel is een manier om kleuren met getallen te beschrijven. Computers hebben die getallen nodig om kleuren op een scherm te laten zien of op papier af te drukken.

Twee bekende kleurmodellen zijn RGB en CMYK. Deze modellen gebruiken verschillende basiskleuren en hebben een ander doel.

RGB: kleuren met licht

RGB staat voor rood, groen en blauw. Beeldschermen gebruiken deze drie kleuren licht om andere kleuren te maken.

Bij RGB heeft iedere basiskleur meestal een waarde tussen 0 en 255. Een waarde van 0 betekent geen licht van die kleur en 255 betekent de hoogste ingestelde sterkte.

Als alle drie de kleuren op 0 staan, ontstaat zwart. Als alle drie op 255 staan, ontstaat wit.

Hoeveel RGB-kleuren zijn mogelijk?

Voor iedere kleur zijn er 256 mogelijke waarden, namelijk 0 tot en met 255. Daardoor zijn er 256 × 256 × 256 = 16.777.216 verschillende RGB-combinaties mogelijk bij 8 bits per kleurkanaal.

CMYK: kleuren met inkt

CMYK staat voor cyaan, magenta, yellow (geel) en key (zwart). Printers gebruiken deze inkten om kleuren op papier te maken.

Een beeldscherm maakt kleuren met licht. Een printer werkt met inkt die bepaalde kleuren licht opneemt. Daarom kunnen afgedrukte kleuren er anders uitzien dan op een scherm.

Wat zijn pixels?

Een pixel is een klein beeldpuntje. Digitale afbeeldingen bestaan uit heel veel van deze beeldpunten.

Iedere pixel heeft een kleur. Samen vormen alle pixels een foto, video of afbeelding. De resolutie geeft aan hoeveel pixels een afbeelding heeft.

Decimale en hexadecimale kleurcodes

Op websites kun je kleuren met verschillende codes aangeven. RGB gebruikt decimale getallen. Je kunt dezelfde kleur ook met een hexadecimale code opschrijven.

Het hexadecimale stelsel gebruikt zestien tekens: 0 tot en met 9 en A tot en met F. Een hex-kleurcode begint met een #.

Kleur Decimaal (RGB) Hexadecimaal
Rood rgb(255, 0, 0) #FF0000
Groen rgb(0, 255, 0) #00FF00
Blauw rgb(0, 0, 255) #0000FF
Wit rgb(255, 255, 255) #FFFFFF
Zwart rgb(0, 0, 0) #000000
Mijn menukleur rgb(52, 73, 94) #34495E

Welke kleuren gebruik ik voor mijn website?

Ik heb voor mijn website een donkerblauw menu gekozen. De hex-code daarvan is #34495E. Dezelfde kleur is rgb(52, 73, 94).

Mijn achtergrond is lichtgrijs met de code #F5F5F5. De gewone tekst heeft de donkere kleur #333333.

Ik heb deze kleuren gekozen omdat ze rustig zijn en de tekst goed leesbaar blijft. In mijn CSS-bestand staan deze kleurcodes bij de onderdelen waarop ze worden toegepast.

Maak zelf een RGB-kleur

Verander de hoeveelheid rood, groen en blauw met de schuifbalken. Je ziet de kleur meteen veranderen. Ook verschijnen de decimale RGB-code en de hexadecimale code.
