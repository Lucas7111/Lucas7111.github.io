Over mij

Hoi! Ik ben Lucas en ik ben 15 jaar oud. Ik zit op het Vlietland College in HAVO 4. Voor het vak informatica heb ik deze website gemaakt.

In mijn vrije tijd ga ik graag naar de sportschool. Dat doe ik ongeveer vier keer per week. Daarnaast vind ik het leuk om met vrienden te voetballen.

Mijn toekomst

Later wil ik graag een leuke opleiding volgen en een baan vinden die goed bij mij past. Ik weet nog niet precies wat ik wil worden. Ik hoop dat ik daar door loopbaanoriëntatie en begeleiding op school achter kom.

Op mijn website leg ik vijf onderwerpen uit die te maken hebben met informatica. Je leert hoe computers informatie verwerken, hoe binaire getallen werken en hoe kleuren worden gemaakt. Ook leg ik uit wat compressie is en wat je met kunstmatige intelligentie kunt doen.

Waarom heb ik deze website gemaakt?

Ik heb deze website gemaakt voor een opdracht van informatica. Ik leer hiermee hoe HTML, CSS en JavaScript werken. HTML gebruik ik voor de inhoud, CSS voor de opmaak en JavaScript voor interactieve onderdelen.
