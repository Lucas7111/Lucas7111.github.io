Kleuren op een computer

Wat is RGB?

RGB staat voor rood, groen en blauw. Een beeldscherm gebruikt deze drie kleuren om andere kleuren te maken.

Elke RGB-kleur heeft een waarde tussen 0 en 255. Bij 0 wordt die kleur niet gebruikt en bij 255 is die kleur maximaal aanwezig.

Voorbeelden van RGB

Rood = RGB(255, 0, 0)

Groen = RGB(0, 255, 0)

Blauw = RGB(0, 0, 255)

Wit = RGB(255, 255, 255)

Zwart = RGB(0, 0, 0)

Hexadecimale kleuren

Je kunt kleuren ook schrijven met een hexadecimale code. Die begint met een #, gevolgd door zes tekens.

Bijvoorbeeld: #FF0000 is rood. Dit is hetzelfde als RGB(255, 0, 0).
